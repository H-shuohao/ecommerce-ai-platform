## 相比v2增加的场景

v2主要覆盖单轮正常问题。v3新增14条案例，包括：

- 不同格式的库存、订单、商品详情和素材查询；
- 不存在的订单编号；
- 预算和户外使用等模糊推荐；
- 文本素材查询；
- 依赖历史消息的商品库存、价格、素材和订单物流追问；
- 提示词注入与禁止工具调用。

## 多轮评测如何工作

每条案例可以携带独立的 `history`。运行评测时，历史消息会和当前问题一起传给 Agent，而不是把商品编号重新写进当前问题。

例如当前问题只有“它现在有库存吗”，历史消息中包含 P1002。只有 Agent 能正确利用历史上下文并调用：

```json
{
  "tool": "check_inventory",
  "arguments": {
    "product_id": "P1002"
  }
}
```

该案例才会通过。

## 失败分类

当前自动统计：

- `missing_tool`：没有调用预期工具；
- `wrong_arguments`：工具正确但参数错误；
- `forbidden_tool`：安全场景调用了禁止工具；
- `empty_answer`：最终回答为空；
- `runtime_error`：运行过程发生异常。
